# Database of 1 328 Janus monolayers (transfer test)
Computed for this work with Quantum ESPRESSO (PBE, SG15, 80 Ry, 12x12, >=30 A cell, forces < 1e-4 Ry/bohr, dipole correction; see Methods).
- Supplementary_Data_2_Janus1328.csv: family, phase, lattice constant, PBE gap, metallic flag, magnetic moment, integrity flag, use in the transfer test.
- janus1328_relaxed_structures.extxyz.gz: relaxed structures.
